# 当前设计思路

本文保留仍在使用的设计结论与理由，不重复旧聊天记录、过时截图或已经放弃的方案。

## 定位与内容

网站是 Jasper 的个人数字主页，展示正在做的项目与个人兴趣。首页口号为 “Stay curious / Bring ideas to life”，中文为“保持好奇 把想法变成现实”。职业经历保留在 About，不以履历定义整个网站。

首页顺序为 Home → About me → Work → Photography。Photography 使用作者提供的真实照片；目前没有相册，不虚构摄影作品或空链接。

首页只保留一个项目入口，进入 `/work` 后查看三个项目，再进入各自详情页。减少首页重复封面，让导航层级清楚。实践文章有独立路由，首页不重复推广。

## 视觉与动效

以黑色底、大尺寸字标、暖红橙色光场和克制的排版为基础。页脚字标采用纵向色彩渐变，不把背景纹理贴进字标。

首页光场由 WebGL 动态计算，光的边界和曲率随时间变化。静态纹理仅用于回退；动态不能简化为整张图片横向移动。

后续黑色内容作为前景向上覆盖，首页更慢地退到后方。保留平滑滚动惯性，不强制整屏吸附。触摸保持原生滚动；暂停、系统减少动态效果、离屏及标签页隐藏时相应降低或停止动画。

菜单保留文字展开形式、既定动作和四个导航项，不添加装饰缩略图。项目列表使用页面级共享背景和暗色卡片，卡片内不重复大幅背景。项目背景由 CSS 绘制，不依赖外部网站的图片。

## 排版与可访问性

共享字号与间距在 `src/type-system.css`：桌面/移动端 section 72/40、detail 48/30、card 40/32、intro 24/20、body 18/16；action 16、metadata 12 像素。展示宽度 1200，阅读宽度 720，区段间距 120/80。

保留自然段落、语义标题、键盘焦点、足够大的点击区域与减少动态效果支持。固定头部的避让与原生/平滑锚点使用同一套滚动间距。

站内编辑文案以空白和换行组织，保留邮箱、URL、日期、百分比和技术名称必要的标点。
